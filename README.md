## About

I build AI systems that have to work under pressure: offline, adversarial, or at the protocol level. My work sits where agent orchestration, security and systems programming meet. I also publish research (15+ papers: IEEE conferences, a SAGE journal, book chapters).


## What I work on

- **Agentic systems:** LangGraph, MCP, A2A, Google ADK, LangFuse tracing, Guardrails
- **AI security:** adversarial multi-agent testing, anti-spoofing, synthetic-media forensics
- **Systems:** Rust and C++ for DNS (DoT/DoH/DoQ, DNSSEC), a Wayland compositor, lock-free structures
- **Edge AI:** INT8 quantization, TFLite and ONNX, hybrid on-device/cloud model routing
